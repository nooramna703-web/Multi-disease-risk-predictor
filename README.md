#Multi-Disease-Risk-Predictor
An AI-powered machine learning application designed to predict potential health risks for Diabetes, Chronic Kidney Disease (CKD), and Anemia, including anemia types, using health-related data.
Project Overview
This project uses machine learning to identify potential disease risks based on selected health indicators. It provides explainable results to help users understand the factors influencing their predicted risk.
The application is designed as a preliminary risk-screening tool, not a medical diagnostic system.

Key Features
Multi-Disease Risk Prediction: Predicts potential risks of Diabetes, CKD, and Anemia.
Anemia Type Prediction: Provides risk-related insights into different anemia types.
Explainable AI: Highlights the top three factors influencing the predicted risk.
User-Friendly Interface: Developed using Streamlit.
Health Risk Awareness: Helps users better understand potential health risks.
Technologies Used

●Streamlit

Dataset
The models were trained using health-related data from the National Health and Nutrition Examination Survey (NHANES), a publicly available dataset.
How It Works
Users enter relevant health information.
The application processes the input data.
Machine learning models estimate potential disease risks.
The application displays prediction results.
Explainable insights highlight the top three contributing risk factors.
Important Medical Disclaimer
This application is developed for educational and preliminary health-risk screening purposes only. Its predictions are not medical diagnoses. Users should consult qualified healthcare professionals before making any medical decisions.
project Purpose
The goal of this project is to explore how machine learning and explainable AI can support health-risk awareness while promoting responsible and transparent use of AI in healthcare.
Developed as a Data Science and Machine Learning Portfolio Project.
